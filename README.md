# ResortEase: A Web-Based Integrated Property Management, Reservation, and Guest Services System
ResortEase, an integrated property management, reservation, and guest services system.<br/>
**Requirements for CC03 – Intermediate Programming.**

## Abstract
Most resort establishments nowadays rely on manual logbooks, isolated spreadsheets, and informal messaging channels to manage guest bookings, room and pool amenity scheduling, store sales, and guest service inquiries. This manual workflow has resulted in scheduling conflicts such as double bookings, delayed billing calculations, unrecorded store inventory movements, and slow guest responses, especially outside operational hours. This study aimed to develop ResortEase, an integrated property management, reservation, and guest services system using Python and MySQL. The system enables front desk operators to manage reservations, assign rooms and pool amenities, generate printable E-Invoices and E-Receipts, send automated confirmation emails including resort rules and policies, track point-of-sale store sales and consumables inventory, and view real-time financial analytics. The system was developed using the Prototyping Model and was evaluated through black-box functionality testing and developer-led integration testing using simulated operational scenarios. Results showed that the system successfully prevented double-booking errors, accelerated invoice generation, and maintained accurate tracking of inventory and sales.
